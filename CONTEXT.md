# Sitio web del Dr. Andrés Villar

## Objetivo

Landing estática independiente de GoHighLevel para presentar de forma breve los servicios de cirugía general del Dr. Andrés Villar y dirigir la conversión a WhatsApp.

## Decisiones de diseño

- Se conserva la identidad visual del sitio anterior: Lora, Figtree, azul marino, dorado y marfil.
- El hero usa `ChatGPT Image 4 sept 2026, 03_46_31 p.m. 1.png` como fotografía de fondo de ancho completo. El título se redujo en escritorio y se conserva el tratamiento móvil.
- Trayectoria usa `portrait - 2.png`, con proporción natural para evitar recortar el rostro.
- El navbar usa el monograma corto `Favicon-01.png`; el pie usa `Logotipo-02.png` completo y con altura automática.
- Los fondos `fondo-01.png` y `fondo-02.png` se utilizan en trayectoria y reseñas, respectivamente.
- Las preguntas funcionan como acordeón exclusivo: abrir una cierra la anterior.
- La estructura se limita a servicios, trayectoria, reseñas, preguntas frecuentes y ubicación. Se eliminó el proceso paso a paso y el contenido repetido.
- El hero queda preparado para sustituir la imagen por video más adelante, sin mostrar controles ni espacios vacíos por ahora.
- La implementación es HTML, CSS y JavaScript sin framework ni proceso de compilación.

## Datos pendientes del cliente

- Número definitivo de WhatsApp.
- Cédula profesional y cédula de especialidad confirmadas.
- Testimonios reales y autorización para publicarlos.
- Confirmación de precio de consulta, dirección y cifras de trayectoria.
- Video del doctor para una posible actualización del hero.

La versión de revisión identifica los datos provisionales y evita abrir WhatsApp con un número ficticio.
